# vagabond-lite
#### Project setup
1. Install foundry
2. Install pnpm: `pnpm install`
3. Build and run tests: `pnpm build` && `pnpm test`
4. Copy or symlink the contents of `dist` to your Foundry user Data/systems directory.
5. Start Foundry: `pnpm foundry` (update Foundry location & user data path)
6. Start dev server: `pnpm vite` or `pnpm vite-no` (doesn't auto-launch a browser)
