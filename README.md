# vagabond-lite
#### Project setup
1. install foundry,  we recommend Node.js to: C:\Program Files\FoundryVTT-Node
2. install pnpm: `pnpm install`
3. build and run tests: `pnpm build` && `pnpm test`
4. start foundry: `pnpm foundry` (this will only work if you did step 1)
5. start dev server: `pnpm vite` or `pnpm vite-no` (no not auto-launch a browser)
